# 📌 Project Overview

The **Hotel Revenue Analysis Dashboard** is an **end-to-end Business Intelligence project** built using **Python, SQL, Power BI, and Excel**.

The project converts raw hotel booking data into meaningful insights that help hotel managers optimize revenue, monitor occupancy, reduce cancellations, and improve customer experience.

### ✨ Key Highlights

✅ Data Cleaning using Python

✅ Exploratory Data Analysis (EDA)

✅ SQL Business Queries

✅ Interactive Power BI Dashboard


```bash

```

## Launch Notebook

```bash

```
